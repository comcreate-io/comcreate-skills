# Public Release Checklist

- [ ] At least five core skills have cleared provenance.
- [ ] Two developers have completed clean Codex and Claude Code installations.
- [ ] A developer other than the initial maintainer has contributed through a pull request.
- [ ] Deterministic CI passes on the release commit.
- [ ] Every core skill has complete behavioral cases and dual-runtime replay evidence.
- [ ] External catalog entries have source and license status.
- [ ] Repository and Git history scans contain no secrets or private material.
- [ ] README, contributing guide, security policy, examples, and changelog are current.
- [ ] Maintainers have approved the final visibility change.

Keep the repository private until every item is checked.
